# V26 Illustrative Preview Archive

This folder preserves the original V26 illustrative carousel and its generator as
historical visual-design references.

- `report-preview-illustrative-v26.gif` is a synthetic illustration, not a Power BI
  Desktop capture.
- `build_sample_preview_v26.py` generated that illustration from the repository's
  deterministic sample data. It is an unchanged historical snapshot and expects
  its original repository-root location if it is run.

The current public preview uses actual Power BI captures from the V27 In Testing
template. Do not use this archive as evidence of report rendering or metric
behavior.
