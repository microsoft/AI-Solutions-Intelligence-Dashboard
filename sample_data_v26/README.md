# AI Solutions Dashboard v26 Sample Data

This package contains the 13 CSV files used by both
`AI-Solutions-Intelligence-Dashboard V26 Validated.pbit` and
`AI-Solutions-Intelligence-Dashboard V27 In Testing.pbit`.

- The dataset is fully synthetic and generated with deterministic seed `20260504`.
- It contains 3,069 illustrative data rows.
- All sample user identities use the fictional `contoso.com` domain.
- It contains no tenant export or real employee data.

## Test the template

1. Extract the ZIP while keeping all 13 CSV files together in one folder.
2. Open `AI-Solutions-Intelligence-Dashboard V27 In Testing.pbit` in Power BI Desktop, or use V26 Validated for the stable release.
3. For `AI_Data_Folder_Path`, select the extracted sample-data folder.
4. Load the report.

Do not use the synthetic metrics for operational or governance decisions.
